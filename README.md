# iisg-tastade-ontology
This repository hosts the Tastade ontology and data model documentation.

[Tastade](https://iisg.amsterdam/nl/Tastade) is an ERC research project about the history of the Trans-Atlantic Slave Trade and the Development of Europe.

The data model has evolved since the project started in March 2026, generating different versions of the ontology (and of the data entry Editor). See the Release notes for more information.
